# Geological Data

Geological Data is a standalone application mode for geophysical events, hydrology, terrain data, and geoscience catalogs. It appears directly in **Map Data → Pipelines**.

## Sources

- USGS Earthquakes
- USGS Water Data
- USGS The National Map
- USGS ScienceBase

## Workflow

1. Select **Geological Data** from the Pipelines radio control.
2. Review the active location and coordinates.
3. Configure a USGS source and run the request using the existing controls.
4. Inspect the **Loaded** document pane and use the existing text processing, embedding, or storage tools.

Existing `geo_*` session-state keys and processing pipelines are retained. This mode does not modify the Interactive Map or its geographic database.
