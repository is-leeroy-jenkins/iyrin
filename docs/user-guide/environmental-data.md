# Environmental Data

Environmental Data is a standalone application mode for atmospheric, environmental, fire, and natural-event services. It appears directly in **Map Data → Pipelines**.

## Sources

- EPA AirNow Air Quality
- UV Index
- OpenAQ
- PurpleAir
- EPA Envirofacts
- NASA FIRMS fire data
- NASA EONET natural events

## Workflow

1. Select **Environmental Data** from the Pipelines radio control.
2. Review the active location, ZIP code, and coordinates.
3. Expand a source, configure its existing inputs, and retrieve results.
4. Inspect the **Loaded** document pane and use the source-specific processing controls.

Existing `env_*` session-state keys, clear actions, result rendering, and source-processing pipelines remain intact.
