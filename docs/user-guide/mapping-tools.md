# Mapping Tools

Mapping Tools centralizes direct geographic utility operations.

## Capabilities

- Address and coordinate geocoding.
- Place lookup.
- Distance and travel-time calculations.
- Coordinate-based time-zone resolution.
- Static map generation.

## Modules

| Module | Responsibility |
|---|---|
| `../../mapping.py` | Shared mapping gateway. |
| `geocode.py` | Address and coordinate geocoding. |
| `places.py` | Place search and details. |
| `distances.py` | Distance Matrix and travel metrics. |
| `timezones.py` | Time-zone resolution. |
| `staticmaps.py` | Static map generation. |
